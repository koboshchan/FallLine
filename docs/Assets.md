# Asset sources and restoration

## Included assets

The imported snow, boulder and pine/fir environment assets are derived from Poly Haven's CC0 assets. Source manifests retain download URLs and checksums.

https://polyhaven.com/a/snow_02
https://polyhaven.com/a/boulder_01
https://polyhaven.com/a/pine_sapling_medium
https://polyhaven.com/a/fir_tree_01
https://polyhaven.com/license

The ski geometry is generated by `Scripts/GenerateSkiGeometry.py`; no external ski model was used. The materials and gameplay code are project-authored.

The processed `SourceAssets/DEM/verbier.r16` heightmap and terrain in the map derive from swissALTI3D. **©swisstopo**. Redistribution and processing are allowed with source attribution under https://www.swisstopo.admin.ch/en/terms-of-use-free-geodata-and-geoservices . The source manifest and route-selection records are retained. Raw GeoTIFF downloads, Python dependencies, caches and logs are excluded. To regenerate the heightmap, install numpy, rasterio, pyproj and Pillow in a separate Python environment and run `Scripts/PrepareRealDEM.py`; inspect its main entry point before use. The preserved heightmap is sufficient for the existing map.

## Excluded Epic assets

`Content/Characters/` is deliberately excluded, including Manny, Quinn, rigs, materials and textures copied from Epic's installed Third Person template. They are not project-owned or CC0, so this public source repository does not redistribute their editable files.

Install the UE 5.8.4 template resources through your own Epic installation. Check `SOURCE` in `Scripts/import-skier-template.py`, then run it from the project root with Python 3. It restores the mannequin at the original `/Game/Characters/` paths and refuses to overwrite differing files. This is required for the skier visuals.

No Fab, Quixel or Megascans assets are included. Fab alternatives were researched but not acquired. Future assets with paid, restricted or unverified licenses must stay out of the public repository until reviewed.

## Raw source downloads

Poly Haven FBX, Blender files and texture downloads are omitted to avoid duplicating large reproducible sources. The imported CC0 Unreal assets are included through Git LFS. Use each asset page and the corresponding source manifest if you need to rebuild a derivative, then run the relevant download/export/import scripts after reviewing their local paths.
